# Project Structure

This repository is organized around the project’s main concerns:

- `app/` – main PHP pages and user-facing application screens
- `lib/` – shared PHP configuration, page includes, and reusable logic
- `style/` – shared styling for the application
- `images/` – branding assets and graphics
- `demoData/` – sample SQL schema and dataset files
- `sql/` – import scripts and database setup helpers
- `assets/` – application assets and supporting classes
- `docs/` – project notes and documentation

The app entry points live in `app/` so the project is cleaner and easier to navigate for portfolio presentation.
